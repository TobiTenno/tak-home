Map data & providers

T.REX ARMS Maps (default provider `trex`)

maps/providers/trex/ downloads regional extracts and (optionally) sprites from T.REX ARMS tile hosts.

Resource URL
Map server (print / export UI) maps.trex-arms.com
Tile / archive base used by fetch https://tiles.trex-arms.com/maps (see maps/providers/trex/fetch.sh)
Company / product notes trex-arms.com

Attribution strings baked into generated basemaps typically credit OpenStreetMap, OpenMapTiles, and related open/public-domain layers compiled by T.REX ARMS. Sprites under maps/data/sprites/ are proprietary T.REX assets for local deploy only — do not commit or redistribute. Operators are responsible for complying with T.REX ARMS terms for any data they fetch.

Tool used for extracts: protomaps/go-pmtiles (protomaps/go-pmtiles image).

OpenTopoMap (provider `opentopomap`)

Remote ZXY raster layer — nothing is downloaded into maps/data/.

Resource URL
Tiles https://tile.opentopomap.org/{$z}/{$x}/{$y}.png
Project opentopomap.org
License / attribution OpenStreetMap data; see their site for current tile usage policy

Optional Google basemap layers

CloudTAK can show Google slippy layers when CSP allows mt* / khms* hosts (see config/cloudtak.env.template). Those tiles are Google’s, not part of this repo. Follow Google Maps Platform / Maps terms for any production use.
